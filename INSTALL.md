# Ultimate Vocal – instalación en Windows

1. Copia la carpeta **`Ultimate Vocal.vst3`** a:

   `C:\Program Files\Common Files\VST3\`

2. Abre Ableton Live → *Preferencias → Plug-ins* → activa **Use VST3 Plug-in System Folders**
   y pulsa **Rescan**.
3. Busca **Ultimate Vocal** en *Plug-ins* y arrástralo a una pista de audio con voz.

`Ultimate Vocal (Standalone).exe` es una versión independiente para probar sin DAW.

## Notas
- El plugin informa su latencia al DAW (~39 ms); Ableton la compensa automáticamente.
- Para el efecto "robótico" tipo T-Pain: Retune = 0 ms, Cantidad = 100 %.
- Para una corrección natural: Retune 20–60 ms, escala de la canción y Cantidad 70–100 %.
